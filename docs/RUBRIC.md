## Requirements

- Blockchain/Web3 problem and meaningful use: direct ERC-4626 withdrawal mechanics, EVM execution, Ethereum sDAI evidence.
- Working prototype: four disposable vault configurations, browser workflow, independent kit, setup and verification commands.
- GitHub source and setup: public repository accompanies the entry.
- Video: edited walkthrough of real captured app states, with synthetic narration. It does not show wallet-extension signing.
- Brief presentation: six-slide deck covering problem, solution, implementation evidence, intended benefit, and future gates.
- Originality: built from the ExitDrill brief during this event; third-party libraries remain attributed in THIRD_PARTY_NOTICES.
- Eligibility: Devpost reports this account already registered. This review does not invent new personal eligibility declarations.
